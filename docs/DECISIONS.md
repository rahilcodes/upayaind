| D-001 | **Prisma 7** (`prisma-client` generator + `@prisma/adapter-pg`) instead of Prisma 5/6 classic engine. | Rust-free query engine, smaller serverless bundles, works with Neon/Supabase pooling. Same schema language; spec says "Prisma". |
| D-002 | Added `scripts/migrate-wasm.mjs` (`pnpm db:migrate:offline` / `db:deploy:offline`). | Some sandboxes can't download Prisma's native schema engine. The script uses Prisma's official WASM schema engine and writes standard migrations. CI/Vercel use the normal CLI. |
| D-003 | Schema additions beyond §8: back-relations required by Prisma; `AuthToken` (verify/reset/invite, hashed); `Counter` (invoice numbers); `JdAnalysisCache`; `ProductEvent`; helper fields (`Market.locale`, `StudentProfile.assignmentQueue/awaitingSince/consentVersion/internalNotes`, `Subscription.remindersSent`, `ResumeVersion.jdHash/validation/coverLetter`, `Message.isBroadcast/emailedAt`, `LeaveRequest.coverEmployeeId`, `LoginEvent.email/reason`, `CmsEntry.canonicalUrl/noindex/sortOrder`, `FileObject.studentId/filename`, `MockInterview.durationMin/meetingLink`, `User.lastActiveAt/deletionRequestedAt`). | D-021 | **Dev-only simulated payment.** Only when `NODE_ENV !== "production"` AND Stripe isn't configured, `/app/checkout` shows a "Test mode: simulate payment" step. | D-022 | **Webhook idempotency = `WebhookEvent` row + processing lease + unique `Payment.providerPaymentId`.** The event is recorded by `event.id`; one delivery claims a 5-minute lease (`error = "processing:<ms>"`), concurrent duplicates get `409` so Stripe retries; processed events are skipped. `providerPaymentId` is the Stripe invoice id (subscriptions) or payment-intent id (one-time), so `checkout.session.completed` and `invoice.paid` for the same charge create one Payment. | D-023 | **Invoice numbers** `UPY-<year>-<6 digits>` come from a per-year `Counter` row (`invoice:<year>`) incremented with a single `UPDATE … RETURNING` inside the Payment transaction; the first number of a year continues after the highest existing (seeded/imported) number. PDFs are rendered with @react-pdf (brand band, business details from `Settings.business[marketCode]`, discount + tax lines), stored privately with purpose `invoice` and the student id, downloaded via `/api/files/<id>`. LETTER for en-US/en-CA, A4 elsewhere. | Sequential, gap-free under concurrency; per-market legal details (§11 Settings). |
